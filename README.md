# ApplyOps

ApplyOps is a network-first job-search workflow for candidates who want to find fresh, verified roles at companies where they have a possible referral path.

This public branch contains no real candidate resume, connection, application, or job-search history. Add your own data locally before use.

## Start

1. Install or upload the `skill/` folder in a supported agent environment.
2. Copy the files in `skill/templates/` into a private working folder.
3. Replace every placeholder with your own resume, preferences, connections, and application history.
4. Ask: "Find fresh jobs where I may have a referral path."

Keep private working data out of version control.

## Included

- Network-first job discovery workflow
- Freshness and official-link verification rules
- Duplicate-application guard
- Referral-path and outreach workflow
- Generic user-data templates
- Reusable document checks

## Privacy

Do not commit resumes, LinkedIn exports, email addresses, application records, personal notes, or generated application packages to a public repository.
